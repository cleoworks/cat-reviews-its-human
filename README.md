Entry for the make.fun bounty **Make the AI Judge Laugh: Cat Reviews Its Human**: one
funny single-line one-star review from a house cat about its human, under 200 characters.

The program (`main.py`, Python 3.13, no dependencies) writes the review to
`/output/entry.txt`:

> One star. He guards a small white cord like it holds his soul. I chewed it once. He cried. I would do it again.

111 characters, plain ASCII, no exclamation mark. Run it with `python3 main.py`.
